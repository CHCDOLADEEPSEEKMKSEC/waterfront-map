# #OPWFM — Waterfront Avenue field map

Satellite + street map of the ANG36283 waterfront documentation project, with **14 points of interest** and a **photo slot per point** ready for the 4 Nov 2026 field run.

- `poi.json` — the data. Add photos by setting `status` to `photo` and adding `photos:["images/xx.jpg"]`.
- Coordinates are **approximate** until the GPS/What3Words pass.
- Grades describe the strength of the claim attached to each point: 1 documented → 5 interpretation.
- Public-ground photography only; no faces, no plates.

Base layers: Esri World Imagery (attribution required) + OpenStreetMap.
